# @nikita_lee_lars/analytics-shared

Shared types for analytics system.

## Install

\`\`\`bash
npm install @nikita_lee_lars/analytics-shared
\`\`\`

## Usage

\`\`\`ts
import { ErrorEvent, LogLevel, CreateErrorPayload } from '@nikita_lee_lars/analytics-shared';
\`\`\`

## What's inside

- `events.ts` — типы событий (ErrorEvent, LogEvent, MetricEvent).
- `api.ts` — типы API (requests, responses, errors).
- `constants.ts` — LogLevel, WriteStatus.
